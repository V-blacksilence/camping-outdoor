# Vietnam Camping & Outdoor Ecosystem (CampVN)

A mobile-first, community-driven platform for exploring, verifying, and planning camping and outdoor adventures across Vietnam, starting with high-potential Northern destinations.

Developed under the **Google Antigravity** multi-agent development environment with strict **Human Approval Required** governance.
