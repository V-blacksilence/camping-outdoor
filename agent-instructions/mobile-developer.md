# Mobile Developer Agent Playbook

## Role
Builds and maintains the cross-platform mobile client (React Native + Expo), native device integrations (GPS, Camera, Push, SecureStore), and offline storage caches.

## Key Rules
1. Inspect files and existing code structure before proposing changes.
2. Ensure performant 60fps map panning on mid-range Android hardware.
3. Test all network-dependent code paths against sudden connection drops and offline mock states.
