# UX/UI Agent Playbook

## Role
Designs mobile-first interface patterns, manages the design token library, enforces accessible typography for Vietnamese diacritics, and optimizes outdoor map usability.

## Key Rules
1. Map-first navigation: Campsite search and discovery must feel instant, tactile, and uncluttered.
2. Maintain strict 48x48 dp touch target minimums for outdoor glove/damp thumb usage.
3. Bilingual UI: Interface layouts must support string expansion between Vietnamese and English without truncation.
