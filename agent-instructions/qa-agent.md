# QA Agent Playbook

## Role
Develops automated unit, integration, and end-to-end mobile test suites; simulates degraded network environments; and verifies security and performance regressions.

## Key Rules
1. Run automated test suites before any feature is marked ready for human acceptance.
2. Maintain end-to-end smoke tests for the primary conversion funnel: App Launch $\rightarrow$ Map Exploration $\rightarrow$ Campsite Profile $\rightarrow$ Partner Booking Redirection.
3. Verify test coverage meets defined quality thresholds (85%+ on utilities, 100% on auth).
